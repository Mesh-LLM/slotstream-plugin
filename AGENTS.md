# Slotstream Mesh plugin

Standalone Rust control-plane adapter. Release archives bundle pinned Slotstream and its runtime resources; never download model weights implicitly or stop processes not spawned by this plugin. Follow upstream `slotstream serve --port N` and OpenAI `/v1` contracts. No mesh core changes. Run `cargo fmt --check`, `cargo test`, and `cargo clippy --all-targets -- -D warnings`; clean owned `target/` after verification. Commit with runtime identity. No cloud spend or merges.
